# Codex Tenebrarum

Bible du lore de **Warhammer 40 000**, présentée comme un cogitator impérial : terminal de commande,
carte galactique, frise chronologique, toile des relations, Cartographe de la Black Library,
examen d'acolyte et forge de Chapitre.

Site en ligne : https://kawa34400.github.io/codex-tenebrarum/
